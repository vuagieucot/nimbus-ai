# Nimbus

A cozy stealth-mischief browser game. Play as Nimbus, a fluffy cat, knocking things over around the house without getting caught mid-act by Tuna and Helly. Keep her fed, rested and loved, sneak outside when a door opens, and deal with the neighborhood cats.

> **Made by AI.** Built by an AI (Claude, by Anthropic) from the designer's art pack. Personal project for friends.

## Play

- Open `index.html` in a browser, or visit the hosted link.
- Each day is 4 minutes. Mischief scores points (chain acts for a combo). Owners see in their light cones; getting caught mid-act costs a heart.
- Jump onto furniture (Space); up high you are hard to see. Hide in boxes, baskets and beds.
- Doors to outside only open sometimes. Tom is scary, Cop wants a fight, Chase is fun to chase.
- Nothing is saved: a reload starts fresh.

## Controls

| Action | Keyboard | Phone |
|---|---|---|
| Move | WASD / arrows | Joystick (push far to run) |
| Run | Shift | Run button |
| Jump | Space | Jump button |
| Act (hold for mischief) | E | Paw button |
| Meow | Q | Meow button |
| Map / Pause / Mute | M / Esc / N | Buttons |

## Phone and offline

Hosted over https, the game caches itself for offline play. On iPhone: open in Safari, Share, Add to Home Screen, and open it once while online.
